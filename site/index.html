02 How I work

AI writes most of the lines. I'm accountable for all of them.

My workflow, in concrete terms.

A · PARALLEL AGENTS

I run agents like a small team

I split work into scoped tasks and run several Claude Code agents in parallel: one on a data migration, one on tests, one on UI. Then I review and integrate what they hand back, the way a tech lead would.

B · OWNERSHIP

I own architecture and review

I decide the data model, the boundaries and what ships. I read the diffs. When something breaks in production, it's my problem, and I can debug it without the agent.

C · QUALITY GATES

Tests are the contract

Every project has automated suites and a gate that only ratchets up: 340+ checks on PAR, including headless-browser end-to-end tests on a CDP driver I wrote, and 267 on Crumb. Agents never read real records: when they need to look at data they get a scrubbed copy, and test suites run against throwaway copies that only report pass/fail and counts.

D · THE FACTORY

A pipeline for the routine work

A personal "factory" uses the Anthropic API to score product ideas, draft store listings and summarize reviews, so my build time goes into the product itself.
